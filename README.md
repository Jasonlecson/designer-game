# 平面设计师模拟器 · 职业生涯版

基于 LLM 的交互式职业生涯模拟游戏。从 2010 年起步，扮演一名平面设计师，通过回合制选择书写没有终点的职业生涯。

---

## 技术栈

| 层面 | 技术 |
|------|------|
| 后端 | Python Flask |
| 前端 | 原生 HTML/CSS/JS — 多面板仪表盘 |
| AI 引擎 | OpenAI 兼容 API（DeepSeek / GPT-4 / 通义千问） |
| 属性系统 | XP 累积制，`Level = ⌊√(XP/20)⌋`，上限 20 级 |
| 存档 | 多玩家 Session 隔离，JSON 文件持久化 |

---

## 快速开始

### 1. 创建虚拟环境并安装依赖

```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install flask requests
```

### 2. 配置 API

编辑项目目录下的 `config.json`：

```json
{
  "api_base": "https://api.deepseek.com",
  "api_key": "你的API-Key",
  "model": "deepseek-v4-flash"
}
```

支持任意 OpenAI 兼容接口（如 DeepSeek、GPT-4、通义千问、本地模型等）。

### 3. 启动服务

```bash
python server.py
```

### 4. 开始游戏

浏览器访问 `http://localhost:8765` → 点击「新游戏」创建角色 → 开始你的设计师生涯。

> **提示**：页面顶部「API 配置」按钮可随时修改模型和 Key，无需重启服务。

## 游戏机制

### 核心循环

```
阅读当前剧情 → 选择 2-3 个选项（含 effect 标注）→ 选择 → 弹出下回合剧情
```

- 1 回合 ≈ 1 周，48 回合 ≈ 1 年
- 从 **2010 年 1 月** 开始，年龄自然增长
- 四季轮换触发不同的行业事件（春招 / 年终评审 / 设计周等）

### 6 项核心属性 (1-20 级)

| 属性 | 含义 |
|------|------|
| 🎨 审美判断力 | 视觉品味、设计决策力 |
| 🔧 执行能力 | 落地速度、抗压、改稿效率 |
| 💼 商业思维 | 定价谈判、客户洞察 |
| 🗣 表达能力 | 提案说服、人脉建立 |
| 💡 创意深度 | 概念思考、原创性 |
| 📦 作品集厚度 | 综合产出指标 |

LLM 只输出属性趋势 (`up`/`down`/`flat`)，后端 XP 公式计算精确等级——等级越高，固定 XP 的推进效果越弱，自然制造成长放缓曲线。

### 资源系统

- **精力值 (0-100)**：选项消耗，≤0 强制休息 + 扣除 1000-3000 元医疗费
- **储蓄 (元)**：初始 3000，项目酬劳、跳槽、医疗费等影响，储蓄为负触发危机

### 8 级头衔晋升

见习设计师 → 初级 → 中级 → 高级 → 资深 → 设计总监 → 创意合伙人 → 独立设计大师

### 12 枚成就徽章

属性、精力、回合、NPC 关系等多维度解锁，如「🌱 初出茅庐」「👑 德高望重」「🌑 至暗时刻」「⭐ 六边形战士」等。

### 7 种职业起点

应届生 / 乙方执行 / 甲方品牌 / 设计媒体编辑 / 自由职业 / 印刷厂 / 自定义——不同起点有不同的初始属性优势和叙事方向。

### NPC 动态关系

6 类角色（导师、竞争对手、客户、搭档、行业暗流、职场关系），LLM 根据剧情动态更新关系网络，NPC 互动独立于回合推进。

### 属性检定系统

后台运行属性检定（审美/执行/表达检定等），结果自动融入 LLM 叙事，成功或失败都会影响剧情走向。

## API 接口

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/new_game` | POST | 创建新游戏，传入角色设定 |
| `/api/action` | POST | 执行选择 (`choice_id`)，推进一回合 |
| `/api/active_action` | POST | 执行主动操作（休息/休假/社交等） |
| `/api/state` | GET | 获取当前存档状态 |
| `/api/npc/interact` | POST | NPC 互动 |
| `/api/achievements` | GET | 获取成就列表 |
| `/api/export` | GET | 导出存档 |
| `/api/reset` | POST | 删除当前存档 |

## 设计决策

| 决策 | 原因 |
|------|------|
| XP 累积 + 开根号 | LLM 不擅长精确数值，趋势 + 公式更稳定 |
| 20 分制属性 | 10 分到顶太快，50 分超出 LLM 精度 |
| effect 固定 50 XP | 等级越高回报递减，自然制造成长瓶颈 |
| 取消胜负结局 | 职业生涯无终点，低谷是体验的一部分 |
| 2010 年起始 | 给故事一个明确的历史锚点 |
| response_format + 回退 | 优先约束 LLM JSON 输出，4xx 自动放开格式限制 |
| 多玩家 Session 隔离 | 同一服务端支持多人同时游玩 |
| 属性检定 D10 骰子 | 属性和掷骰共同决定成败，制造戏剧性 |

## 常见问题

**Q: 点击选项没反应？**
A: 检查 `config.json` 中的 API Key 是否有效，以及 DeepSeek 账户余额是否充足。如 LLM 调用失败，会自动使用本地兜底内容。

**Q: 如何切换模型？**
A: 点击页面顶部「API 配置」按钮，修改 model 字段即可（如 `gpt-4o`、`qwen-plus` 等）。

**Q: 存档在哪里？**
A: `players/state_<session-id>.json`，一个浏览器 Session 对应一个存档，不同浏览器/设备互不干扰。

**Q: 如何理解属性检定？**
A: 每次关键行为（提案、谈判、设计创作）会自动触发一次检定：`属性值 + D10 vs 难度`，检定结果会融入 LLM 叙事中。
