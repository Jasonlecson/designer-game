# 平面设计师模拟器 · 职业生涯版

基于 LLM 的交互式职业生涯模拟游戏。从 2010 年起步，扮演一名平面设计师，通过回合制选择书写没有终点的职业生涯。

## 技术栈

- **后端**: Python Flask
- **前端**: 原生 HTML/CSS/JS（多面板仪表盘）
- **AI 引擎**: OpenAI 兼容 API（DeepSeek / GPT-4 / 通义千问）
- **属性系统**: XP 累积制，`Level = floor(sqrt(XP/20))`，上限 20 级

## 快速开始

### 1. 安装依赖

```bash
pip install flask requests
```

### 2. 启动服务

```bash
python server.py
```

### 3. 打开游戏

浏览器访问 `http://localhost:8765`，先点击「API 配置」填入你的 API Key，然后创建角色开始游戏。

## 游戏特色

- **无终点职业生涯** — 2010 年起步，年龄随时间增长，没有胜负结局
- **XP 累积制属性** — LLM 只判断趋势 (up/down)，后端公式计算精确等级
- **6 项核心属性 (1-20 级)** — 审美判断力、执行能力、商业思维、表达能力、创意深度、作品集厚度
- **可见后果** — 每个选项标注 effect（「审美+1 精力-8」），固定 50XP 每点
- **资源系统** — 精力值 + 储蓄，精力耗尽强制休息进医院扣钱
- **8 级头衔晋升** — 见习→初级→…→独立设计大师
- **12 枚成就徽章** — 属性、回合、NPC 关系多维解锁
- **动态 NPC 关系** — LLM 根据剧情更新关系网络
- **公司/雇主追踪** — 跳槽、被裁、升职、创业自然推进
